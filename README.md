# 🚀 AI-LAB

Personal laboratory for studying, developing, and experimenting with Artificial Intelligence, Automation, Docker, PostgreSQL, and Business Analysis.

The goal of this project is to build a local, modular, and reproducible environment for developing solutions using Generative AI, workflow automation, databases, and modern development tools.

---

# 🎯 Objectives

- Learn Docker and Docker Compose
- Develop workflow automations with n8n
- Work with PostgreSQL databases
- Study Generative Artificial Intelligence
- Build AI agents
- Develop portfolio projects
- Strengthen technical skills for returning to the IT industry
